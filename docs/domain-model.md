# Domain model

All ids are UUIDs (items added from templates keep the readable template id, e.g. `p-security`); all timestamps are ISO 8601 UTC.

| Entity                                    | Key fields                                                                                                                               | Relations                                                                                                                                                            |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Incident                                  | ref, title, phase, severity, level, classification, tlp, sourceSystem/sourceId, startedAt, detectedAt, awareAt                           | Process (+ processVersion), Task, Decision, TimelineEvent, Communication, Attachment, ImprovementAction, ReportingDeadline (snapshot), Activation, related incidents |
| Process / ProcessVersion                  | name, domain, version, phaseNames (ProcessPhaseMapping), levelNames (ProcessResponseMapping), triage, tasks, templates, IRT/CRT criteria | Roles, ReportingRules, GuidanceSituations                                                                                                                            |
| UniversalPhase                            | report, assess, respond, recover, close                                                                                                  | —                                                                                                                                                                    |
| ResponseLevel                             | standard, elevated, coordinated (IRT), critical (CRT)                                                                                    | —                                                                                                                                                                    |
| Activation                                | team (irt/crt), rationale, by, at, happening, critical, override, stand-down                                                             | Incident                                                                                                                                                             |
| GuidanceSituation / GuidanceVersion       | slug; versions with status draft/review/published/archived                                                                               | Flowchart, Contacts, Roles, Process                                                                                                                                  |
| Flowchart / FlowchartNode / FlowchartEdge | node types start, question, action, contact, escalate, report, end; edge labels                                                          | Contact, Role, Process, ResponseLevel refs                                                                                                                           |
| Contact / ContactVerification             | type, phones, email, availability, out-of-hours, backup, lastVerifiedAt, verifiedBy                                                      | Situations, Processes                                                                                                                                                |
| Role / ResponsibilityAssignment           | responsibilities, decides, skills, onEscalation; RACI per process × phase                                                                | Contacts                                                                                                                                                             |
| ReportingRule / ReportingRuleVersion      | anchor (started/detected/aware), stages (minutes/hours/days/months, from start or previous), effectiveFrom, active, history              | Processes                                                                                                                                                            |
| ReportingDeadline                         | ruleId, ruleVersion, stage, dueAt, status                                                                                                | Incident (snapshot)                                                                                                                                                  |
| ResponseTeam                              | IRT/CRT names, departments, activators, aliases (CSIRT/CERT — informational)                                                             | Settings                                                                                                                                                             |
| SourceSystem / SourceMapping              | status, lastSync, field map, value map, errors                                                                                           | Incidents                                                                                                                                                            |
| User / Permission                         | demo user; named permissions in `src/auth/permissions.tsx`                                                                               | —                                                                                                                                                                    |
| ConfidentialityPolicy                     | HR default classification, masking per view context                                                                                      | Incidents                                                                                                                                                            |
| SystemSetting                             | public settings + secret "configured" flags                                                                                              | —                                                                                                                                                                    |
| AuditEvent                                | at, actor, action, entity, entityId, summary, highlight                                                                                  | everything                                                                                                                                                           |
