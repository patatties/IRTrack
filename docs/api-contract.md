# REST API contract

Implemented by `server/api.ts`, derived from `src/data/ports.ts`. All paths are under `/api`. JSON, UTC ISO timestamps. The acting user is sent in the `X-IRTrack-Actor` header (not authenticated yet). A missing single item (`GET /incidents/:id`, `/guidance/:id`, `/public/track/:ref`) returns `null`. List endpoints accept `page`, `pageSize`, `sort`, `dir` and filters, and return `{ items, total, page, pageSize }`.

| Method       | Path                                   | Repository method                                                                                                                                                                                   |
| ------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET          | /incidents                             | incidents.list (filters: search, domain, phase, severity, minSeverity, level, source, processId, location, service, category, businessUnit, days, open, weekday, hour, ctx)                         |
| GET          | /incidents/:id                         | incidents.get                                                                                                                                                                                       |
| POST         | /incidents                             | incidents.create                                                                                                                                                                                    |
| PATCH        | /incidents/:id                         | incidents.update `{ patch, summary, highlight }`                                                                                                                                                    |
| POST         | /incidents/:id/activations             | incidents.activate                                                                                                                                                                                  |
| POST         | /incidents/:id/deadlines/reapply       | incidents.reapplyRules                                                                                                                                                                              |
| GET          | /public/track/:ref                     | incidents.track (no auth; status only)                                                                                                                                                              |
| GET          | /analytics/dashboard                   | analytics.dashboard (days, domain, processId, source, location, businessUnit, ctx)                                                                                                                  |
| GET/POST/PUT | /contacts, /contacts/:id               | contacts.list / save                                                                                                                                                                                |
| POST         | /contacts/:id/archive, /move, /verify  | contacts.archive / move / verify                                                                                                                                                                    |
| POST         | /contacts/import                       | contacts.importCsv                                                                                                                                                                                  |
| GET/PUT      | /roles, /roles/:id                     | roles.list / save                                                                                                                                                                                   |

| GET/PUT      | /processes, /processes/:id             | processes.list / save (creates a new version)                                                                                                                                                       |
| GET          | /guidance, /guidance/:idOrSlug         | guidance.list / get                                                                                                                                                                                 |
| PUT          | /guidance/:id/draft                    | guidance.saveDraft                                                                                                                                                                                  |
| POST         | /guidance/:id/versions/:v/status       | guidance.setStatus                                                                                                                                                                                  |
| POST         | /guidance/:id/versions/:v/restore      | guidance.restore                                                                                                                                                                                    |
| GET/PUT      | /reporting-rules, /reporting-rules/:id | rules.list / save                                                                                                                                                                                   |
| GET          | /sources, /sources/:id/preview         | sources.list / preview                                                                                                                                                                              |
| POST         | /sources/:id/import                    | sources.runImport                                                                                                                                                                                   |
| GET          | /settings                              | settings.get (never returns secrets)                                                                                                                                                                |

| POST         | /settings/database/test                | settings.testConnection                                                                                                                                                                             |
| GET          | /audit                                 | audit.list                                                                                                                                                                                          |
| GET          | /system/info                           | system.info (version, SQLite version, schema version, database file and size)                                                                                                                       |
| GET          | /health                                | liveness check for the container health check                                                                                                                                                       |
| GET          | /templates/:kind                       | templates.list (kind: contacts, roles, rules, processes, guidance, sources), with `exists` and `requires` per item                                                                                  |
| POST         | /templates/:kind/apply                 | templates.apply `{ ids }`; adds dependencies automatically, returns `{ added, skipped }`                                                                                                            |
| GET          | /templates/playbooks                   | templates.playbooks (incident playbooks)                                                                                                                                                            |
| GET          | /templates/master-data                 | templates.masterData (example values)                                                                                                                                                               |
| GET          | /setup                                 | setup.status `{ completed, completedAt, counts }`                                                                                                                                                   |
| POST         | /setup/complete                        | setup.complete `{ skipped }`                                                                                                                                                                        |
| POST         | /setup/demo                            | setup.loadDemo: fills a new database with the demo data set and completes the setup (409 once setup is done or incidents exist)                                                                     |
| GET          | /ai/providers                          | ai.providers: configured AI providers and default models (keys are never returned)                                                                                                                  |

| POST         | /ai/setup/analyze                      | ai.analyze, `multipart/form-data` with `provider`, `model`, `text` and `files` (PDF, images, .docx, .xlsx, .pptx, text): starts a background analysis, returns the job with per-file handling (202) |
| GET          | /ai/jobs/:id                           | ai.job: `running`, `done` with a proposal, or `error`                                                                                                                                               |
| POST         | /ai/setup/apply                        | ai.apply: saves a reviewed proposal through the regular endpoints and completes setup                                                                                                               |

| POST         | /assistant/message                     | assistant.message `{ chatId?, mode: "portal"                                                                                                                                                        | "admin", message }`: one assistant turn; returns the reply, tools used and changes waiting for approval |
| POST         | /assistant/decision                    | assistant.decide `{ chatId, approve }`: approve or decline the pending changes (admin) and continue                                                                                                 |
